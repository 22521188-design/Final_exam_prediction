"""
1.1 LINEAR REGRESSION MODEL

The linear regression model assumes a linear relationship between input features
and output targets. For our problem:

    Model Equation:
    ŷ = w·x + b

    Where:
    - ŷ (y-hat): Predicted final exam score
    - x: Input feature (midterm exam score)
    - w: Weight parameter (slope of the line)
    - b: Bias parameter (y-intercept)

    Our Trained Model:
    ŷ = 0.800039·x + 2.001839

    Simplified:
    ŷ ≈ 0.80·x + 2.00

1.2 INTERPRETATION OF PARAMETERS

    Weight (w = 0.800039):
    - For every 1-point increase in midterm score, the final score increases
      by approximately 0.80 points
    - This represents a strong positive correlation
    - The slope is less than 1, suggesting some regression to the mean

    Bias (b = 2.001839):
    - This is the predicted final score when midterm score is 0
    - Represents the "baseline" or minimum score
    - In this case, ≈ 2.00, which is close to the observed minimum final score

1.3 LOSS FUNCTION (COST FUNCTION)

    We minimize the Mean Squared Error (MSE):

    L(w,b) = (1/n)·Σ(ŷᵢ - yᵢ)²
           = (1/n)·Σ(w·xᵢ + b - yᵢ)²

    Where:
    - n = 515 (number of training samples)
    - yᵢ = actual final exam score for sample i
    - ŷᵢ = predicted final exam score for sample i
    - Σ = summation over all samples

    Why MSE?
    - Squares the errors, emphasizing larger deviations
    - Always non-negative
    - Differentiable (important for gradient descent)
    - Commonly used in regression problems

1.4 OPTIMIZATION METHOD: ORDINARY LEAST SQUARES (OLS)

    The OLS solution provides closed-form equations for optimal w and b:

    w = Σ(xᵢ - x̄)·(yᵢ - ȳ) / Σ(xᵢ - x̄)²
    
    b = ȳ - w·x̄

    Where:
    - x̄ = mean of all midterm scores
    - ȳ = mean of all final scores
    - (xᵢ - x̄) = deviation of sample i from mean midterm score
    - (yᵢ - ȳ) = deviation of sample i from mean final score

    Intuition:
    - The numerator of w measures co-variation between x and y
    - The denominator of w measures variation in x
    - The ratio gives the best linear slope
    - b is then adjusted to ensure the line passes through (x̄, ȳ)

"""

4.2 DATA FLOW IN FORWARD PASS

    Step 1: Input
    - x = midterm score (e.g., 5.5)

    Step 2: Multiplication
    - z₁ = w × x = 0.800 × 5.5 = 4.4

    Step 3: Addition
    - ŷ = z₁ + b = 4.4 + 2.002 = 6.402

    Step 4: Output
    - Predicted final score = 6.402

4.3 COMPUTATION GRAPH COMPONENTS

    Nodes:
    - Input node: Represents x (midterm score)
    - Parameter nodes: Represent w and b (learned parameters)
    - Operation nodes: Represent mathematical operations (×, +)
    - Output node: Represents ŷ (final prediction)

    Edges:
    - Connections show data flow
    - Direction indicates computation order
    - Allow backtracking (important for training)

    Colors in Visualization:
    - Blue: Input variables
    - Gold: Parameters (w, b)
    - Green: Operations (multiply, add)
    - Pink: Output variables

4.4 COMPARISON: LINEAR vs NEURAL NETWORK COMPUTATION GRAPHS

    Linear Regression (Our Model):
    - Single layer of operations
    - 2 parameters (w, b)
    - Direct path from input to output
    - Closed-form solution available

    Neural Network:
    - Multiple layers (hidden layers)
    - Many parameters (weights in each layer)
    - Complex nested computations
    - Requires iterative optimization (gradient descent)
